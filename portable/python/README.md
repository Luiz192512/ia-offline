# Python portatil

Opcionalmente, voce pode embarcar um Python portatil aqui para deixar o pendrive mais autonomo.

Estruturas esperadas:

Windows:

```text
portable/python/python.exe
```

Linux:

```text
portable/python/bin/python3
```

Os launchers em `scripts/` tentam usar esse Python primeiro e, se ele nao existir, usam o Python instalado no sistema.
