# Base de conhecimento local

Coloque aqui arquivos `.md`, `.txt`, `.json` ou `.csv` com conteudo que deve ser consultado offline.

Boas praticas:

- usar textos curtos e bem organizados;
- separar por assunto;
- evitar arquivos enormes desnecessarios;
- incluir glossarios, manuais, procedimentos ou apostilas.

Os arquivos desta pasta sao usados por busca lexical simples, sem internet.
