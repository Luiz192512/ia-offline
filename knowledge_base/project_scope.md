# Escopo do sistema

Este projeto implementa um assistente conversacional offline, pensado para uso portatil em pendrive de 32 GB.

Objetivos centrais:

- responder perguntas gerais e tecnicas;
- auxiliar em programacao, escrita e resolucao de problemas;
- funcionar totalmente offline;
- operar com modelos compactados e quantizados;
- manter foco em CPU comum e baixo consumo de memoria;
- oferecer interface CLI e GUI leve.

Diretrizes:

- portabilidade acima de desempenho maximo;
- clareza e utilidade pratica nas respostas;
- honestidade sobre incerteza e limitacoes;
- memoria limitada a uma janela curta de contexto;
- nenhuma dependencia de internet ou API externa.
